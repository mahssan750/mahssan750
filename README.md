## Selected projects

### [Retail Data Warehouse](https://github.com/mahssan750/Online_retail)

A SQL Server project that transforms a public UK retail dataset through Bronze, Silver and Gold layers into a sales fact table and customer, product, date and country dimensions. The repository includes the transformation and modeling SQL.

### [Power BI Retail Analytics](https://github.com/mahssan750/online_retail_dashboards)

Dashboard case studies based on a source dataset of more than 500,000 retail transaction lines. The public repository currently provides dashboard screenshots and a model diagram covering sales, customers and product performance.

### [UAE Pharmacy Price and Availability Pipeline](https://github.com/mahssan750/scrab)

A Python and Playwright pipeline for public product pages, with retries, resumable collection and Excel export. The committed snapshot contains **10,188 distinct product URLs**, with a price and availability value for every row. Brand and category coverage is incomplete and documented in the project README. This is a catalogue snapshot, not a live stock feed or evidence of commercial savings.

### [Customer Inactivity Classification](https://github.com/mahssan750/Customer-Churn-Prediction)

An experimental Python project comparing classification models on retail customer behavior. The current target is retrospective inactivity at the dataset snapshot. A future version needs time-based feature windows and an untouched future holdout before it can support prospective churn prediction claims. Financial scenarios in the repository are assumptions, not measured business outcomes.
